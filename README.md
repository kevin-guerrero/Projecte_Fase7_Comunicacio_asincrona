# Daily Bugle - Projecte DAW

Projecte desenvolupat per als mòduls:

* Desenvolupament web en entorn client
* Desenvolupament web en entorn servidor

Inspirat en el diari fictici *Daily Bugle* de Spider-Man.

---

# Branques del projecte

## Branca `main`

Conté la versió desenvolupada per al mòdul:

### Desenvolupament web en entorn client

Tecnologies utilitzades:

* HTML
* CSS
* JavaScript
* Fetch API
* JSON
* Node.js

Funcionalitats principals:

* Visualització de notícies
* Sistema de filtres
* Consum d'API amb JavaScript
* Interfície visual del projecte

---

## Branca `0613`

Conté la migració i adaptació del projecte per al mòdul:

### Desenvolupament web en entorn servidor

Tecnologies utilitzades:

* PHP
* SQLite
* Arquitectura MVC
* API REST
* JWT Authentication

Funcionalitats principals:

* API REST en PHP
* Base de dades SQLite
* CRUD de notícies/articles
* CRUD d'usuaris
* CRUD de categories
* Login i registre d'usuaris
* Autenticació amb JWT
* Separació Model - Vista - Controlador
